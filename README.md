# 📚 单词背诵 · 多单元版

这是一个基于原生 HTML/CSS/JS 编写的轻量级单词背诵卡片网页。无需安装任何软件，打开浏览器即用。

## 🌐 在线访问
点击这里访问：[专属网址]([https://你的用户名.github.io/word-memorizer/](https://backfired-www.github.io/word-memorizer/))

## ✨ 功能特色
- **多教材切换**：支持课本一、课本二及不同单元的自由切换。
- **拼写填空**：看中文拼英文，自动跳过连字符（如 `-` 和空格），支持按 `Enter` 键快速跳转下一格。
- **深色模式**：一键切换，保护视力。
- **收藏本**：遇到难记的单词可以一键收藏，数据保存在浏览器本地，刷新不丢失。
- **纯前端开发**：无后端依赖，所有数据均在本地处理，保证隐私安全。

## 🚀 如何在本地运行
1. 将仓库克隆或下载到本地。
2. 双击打开 `index.html` 即可直接使用。
